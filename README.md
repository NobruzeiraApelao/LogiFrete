# LogiFrete

## Sobre o projeto
O LogiFrete é um sistema web desenvolvido em PHP para auxiliar no gerenciamento de produtos, endereços, transportadoras e fretes.

O projeto foi desenvolvido como atividade prática do curso de Sistemas de Informação da UNIPAR EAD.

## Funcionalidades
- Cadastro e visualização de produtos.
- Cadastro e visualização de endereços de origem e destino.
- Cadastro e visualização de transportadoras.
- Registro de fretes vinculando produtos, endereços e transportadoras.
- Acompanhamento do status dos fretes.
- Relatório de fretes por período, com opção de impressão.

## Tecnologias utilizadas
- PHP
- HTML
- CSS
- MySQL
- PDO
- XAMPP

## Como executar o projeto
1. Instale e abra o XAMPP.
2. Inicie os serviços Apache e MySQL.
3. Copie a pasta do projeto para `C:\xampp\htdocs\logifre`.
4. Abra o navegador e acesse `http://localhost/logifre/setup.php` para configurar o banco de dados.
5. Depois, acesse `http://localhost/logifre/` para abrir o sistema.

## Estrutura do projeto
- `assets/`: arquivos de estilo CSS.
- `includes/`: conexão com o banco de dados.
- `pages/`: páginas de gerenciamento do sistema.
- `index.php`: página inicial.
- `setup.php`: configuração inicial do banco de dados.
